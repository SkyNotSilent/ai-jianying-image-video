# InsightCut 完整产品重做 PRD

版本：v1.0  
日期：2026-06-26  
读者：产品、设计、前端、后端  
范围：完整产品体验重做，默认复用现有 FastAPI、SQLite、本地媒体目录、API 配置与生成链路。

## 1. 背景与目标

InsightCut 是面向知识、科普、观点表达类视频的 AI 解说视频生产工具。当前前端把创建、配置、资产和预览能力压在少数页面中，用户很难理解“我现在处于创作流程的哪一步”，也不利于后续扩展文稿编辑、生产配置、分镜预览、资产复用和失败恢复。

本次重做目标不是做一个更漂亮的一体化页面，而是把产品重构为清晰的多页面 AI 视频生产工作台：

```text
文稿首页 -> 视频生产页 -> 预览编辑页 -> 导出/资产沉淀
项目资产页承载项目预览、历史任务、失败恢复和资产复用。
```

成功标准：

- 用户进入首页后直接进入文稿工作区，可以粘贴文稿、导入文档或使用 AI 辅写生成脚本，不需要先经过项目库。
- 用户能在项目资产页看懂项目状态，并能快速恢复草稿、生成中、失败和已完成项目。
- 文稿输入和编辑成为独立工作区，不被视频参数和预览编辑干扰。
- 生产设置在生成前集中确认模型、画风、比例、配音、字幕和风险提示。
- 预览编辑聚焦成片检查、分镜级修改、单段重生成和导出。
- 任何失败状态都不能隐藏或清空已生成脚本、分镜、图片、音频、字幕和导出记录。

## 2. 用户与场景

目标用户：

- 知识类、科普类、心理学、财经解释、观点表达类短视频创作者。
- 有主题或文稿，但不希望手动完成分镜、找图、配音、字幕和导出的人。
- 需要把 AI 生成结果继续带到剪映/CapCut 精修的创作者。

核心场景：

- 从一个创作要求或已有素材生成视频脚本，再生成分镜图片、配音和字幕。
- 粘贴已有文稿，快速拆分为视频分镜并生成素材。
- 任务失败后继续查看已生成资产，局部修复并重新生产。
- 对单个分镜换图、改 prompt、重配音，再导出 MP4 或剪映草稿。

## 3. 产品架构

### 3.1 全局导航

顶部导航固定包含：

- `文稿`：产品首页，进入文稿编辑页，承载文稿输入、AI 辅写、文档式编辑和基础生成设置。
- `项目资产`：进入项目资产页，承载项目预览、历史任务、资产恢复和完成记录。
- `API 配置`：进入 API 配置页。用户开始真实生产前必须完成生文、生图和 TTS 配置。
- 搜索：搜索项目名称、主题、标签。
- 任务/通知状态：展示生成中、失败、可恢复任务数量。

### 3.2 页面关系

```text
文稿首页 / 文稿编辑页
  -> 粘贴或导入完整文稿 -> 文稿画布 -> 视频生产页
  -> 输入 AI 生成要求 -> AI 辅写脚本 -> 文稿画布 -> 视频生产页
  -> 视频生产页
      -> API 配置检查
      -> 生成中
          -> 预览编辑页
              -> 导出页

项目资产页
  -> 打开已有任务
      -> 草稿：文稿编辑页
      -> 生成中：生成中页面
      -> 失败：预览编辑页或文稿编辑页，优先展示已保存资产
      -> 已完成：预览编辑页
```

### 3.3 项目生命周期

| 状态 | 含义 | 默认入口 | 用户可操作 |
| --- | --- | --- | --- |
| `draft` | 仅有项目名、AI 生成要求或文稿，未开始生产 | 文稿编辑页 | 编辑文稿、进入生产设置、删除 |
| `ready` | 文稿已保存，生产参数已配置，未提交任务 | 视频生产页 | 修改配置、开始生产 |
| `pending` | 任务已提交，等待执行 | 生成中页面 | 返回文稿首页、查看状态 |
| `processing` | 任务执行中 | 生成中页面 | 返回文稿首页、查看阶段进度 |
| `failed` | 任务失败，但可能有部分资产 | 预览编辑页 | 查看已保存素材、重试、局部重生成 |
| `completed` | 初始生产完成 | 预览编辑页 | 编辑分镜、导出 |
| `exported` | 已生成 MP4 或剪映草稿 | 导出页/预览编辑页 | 下载、重新导出、继续编辑 |

## 4. 核心页面需求

### 4.1 文稿编辑首页

页面目标：作为产品首页，用户打开产品后直接进入创作起点，而不是先进入项目库。首页以文稿为主，不再保留旧的“短主题/完整文稿”双模式；短主题、要求、提纲都归入 AI 辅写要求，最终必须落到可编辑文稿。

主要模块：

- 左侧项目设置：
  - 项目名称。
  - 内容来源：AI 辅写、粘贴文本、导入文档。
  - AI 辅写要求：填写创作方向、受众、语气、时长目标，点击“AI 生成脚本”。
  - 文稿输入：粘贴或编辑完整文稿，直接进入脚本画布。
  - 预计时长、分镜预估、正文字符。
- 中央文稿画布：
  - 文档式编辑区域。
  - 标题、正文、章节、小标题、列表。
  - 自动保存状态：已保存 / 保存中 / 保存失败。
- 右侧基础生成设置：
  - 画面风格。
  - 视频比例。
  - 创作风格。
  - 配音音色。
  - 语速。
- 底部操作栏：
  - `预览脚本`。
  - 文稿为空但填写了 AI 辅写要求时显示 `AI 生成脚本`。
  - 文稿已就绪时显示 `下一步：生产设置`。

状态规则：

- 首页默认可以创建一个本地草稿。
- 刷新后应恢复当前本地草稿。
- 未形成文稿前不能直接提交生产，必须先生成或填写脚本。
- 已有文稿可以直接进入生产设置。

### 4.2 项目资产页

页面目标：作为资产入口，承担项目预览、历史任务、筛选、恢复和资产复用。项目预览不放在首页，统一进入项目资产页。

主要模块：

- 顶部导航与搜索。
- 左侧筛选：项目状态、视频风格、时长、创建时间。
- 中央项目列表/网格：
  - 封面图或占位状态。
  - 项目名称、状态、时长、更新时间。
  - 模型/提供商标签，如 Agnes、MiMo、LiteLLM。
  - 操作：打开、继续编辑、删除、导出。
- 右侧快速新建面板：
  - 项目名称。
  - 内容来源：文稿 / AI 辅写。
  - 入口按钮：`创建文稿`。

状态规则：

- 空状态：提示“还没有项目”，主按钮为“创建第一个视频”。
- 加载态：项目列表骨架屏，右侧创建面板可用。
- 失败项目：不能只显示失败标签，必须显示“已保存素材数量”或“可恢复”入口。
- 生成中项目：显示最近阶段和进度，不阻塞用户打开其他项目。

### 4.3 文稿编辑页

页面目标：独立处理内容输入、AI 脚本生成、文稿编辑和自动保存。该页面同时也是首页。

主要模块：

- 左侧项目设置：
  - 项目名称。
  - 内容来源：AI 辅写 / 粘贴文稿 / 导入文档。
  - AI 生成脚本按钮。
  - 预计时长、字数、段落数量。
- 中央文稿画布：
  - 文档式编辑区域。
  - 标题、正文、章节、小标题、列表。
  - 基础工具栏：撤销、重做、正文样式、字号、加粗、斜体、列表。
  - 自动保存状态：已保存 / 保存中 / 保存失败。
- 右侧基础生成设置：
  - 画面风格。
  - 视频比例。
  - 创作风格。
  - 配音音色。
  - 语速。
- 底部操作栏：
  - `预览脚本`。
  - `下一步：生产设置`。

字段规则：

- 项目名称必填，建议上限 100 字。
- 文稿正文必填，AI 辅写要求建议 100 字以内，文稿正文建议 5000 字以内。
- 自动保存不应依赖用户点击下一步；刷新后必须能恢复当前文稿。

### 4.4 视频生产页

页面目标：在真正提交生成任务前，集中确认生产参数、API 配置、额度和风险。

主要模块：

- 左侧文稿摘要：
  - 项目名称、脚本字数、预计时长。
  - 自动分镜预估。
  - “返回文稿编辑”入口。
- 中央生产配置：
  - 生文配置：协议、模型、Base URL 状态。
  - 生图配置：Agnes Image 2.1 Flash、比例、画风、并发提示。
  - TTS 配置：provider、音色、语速、字幕开关。
  - 导出模板：MP4、剪映草稿。
  - 高级设置默认折叠。
- 右侧生产检查：
  - 文稿已保存。
  - API 配置可用。
  - 本地媒体目录可写。
  - 失败也保留素材。
  - 今日额度/限速提醒。
- 底部操作栏：
  - `返回文稿`。
  - `开始生产`。

生成规则：

- 点击开始生产前必须读取 API 配置并检查完整性。
- 生文、生图、TTS 任一必要 API 缺失时，阻止提交并引导进入 API 配置页。
- 点击开始生产后调用现有任务创建接口。
- 生产页必须把文稿和参数组装为任务 payload。
- 如果配置缺失，阻止提交并给出明确原因。
- 任务提交成功后进入生成中页面。

### 4.5 预览编辑页

页面目标：查看成片、编辑分镜、替换资产、局部重生成并进入导出。

主要模块：

- 左侧项目导航：
  - 文稿。
  - 生产设置。
  - 预览编辑。
  - 导出。
- 中央预览区：
  - 大播放器。
  - 字幕叠加。
  - 播放、暂停、时间轴、倍速、全屏。
- 分镜表格：
  - `#`、时间、文案、画面、配音、状态、操作。
  - 按 `segment_index` 播放顺序展示。
  - 选中行高亮。
- 右侧片段检查器：
  - 片段范围。
  - Prompt 文本框。
  - 智能优化。
  - 画风候选/历史图片。
  - 配音设置。
  - 字幕设置。
  - 重生成当前片段。
  - 应用到全部。
- 底部操作栏：
  - `返回生产设置`。
  - `导出视频`。

编辑规则：

- 修改文案、图片、配音后，预览状态应标记为需要重新渲染。
- 单段失败不应导致整个分镜表隐藏。
- 图片缺失、音频缺失、字幕缺失必须在该段状态中可见。
- 所有上传、替换、重生成都必须进入项目资产。

## 5. 生产链路

```text
用户输入 AI 辅写要求或文稿
  -> 文稿保存
  -> 生产参数确认
  -> 创建任务
  -> 脚本改写/整理
  -> 分镜切分
  -> 图片 prompt 生成
  -> 图片生成
  -> TTS 配音
  -> 字幕生成
  -> 预览/草稿构建
  -> 预览编辑
  -> MP4 或剪映草稿导出
```

关键原则：

- 任务一旦有中间产物，就必须保存到数据库和本地媒体目录。
- 任务失败只表示后续流程停止，不代表已有资产失效。
- 前端必须允许用户从失败任务进入可恢复页面。
- 导出应基于当前分镜状态，而不是只基于最初生成结果。

## 6. 数据与接口需求

### 6.1 可复用现有接口

- `GET /ai/native/video/kepu/tasks`：项目资产页列表。
- `POST /ai/native/video/kepu/tasks`：提交生产任务。
- `GET /ai/native/video/kepu/tasks/{task_id}`：任务状态。
- `GET /ai/native/video/kepu/tasks/{task_id}/segments`：预览编辑分镜表。
- `PUT /ai/native/video/kepu/tasks/{task_id}/segments/{segment_index}`：保存分镜文案或图片字段。
- `POST /ai/native/video/kepu/tasks/{task_id}/segments/{segment_index}/regenerate-image`：重生成图片。
- `POST /ai/native/video/kepu/tasks/{task_id}/segments/{segment_index}/regenerate-audio`：重生成配音。
- `POST /ai/native/video/kepu/tasks/{task_id}/segments/{segment_index}/upload-image`：上传替换图片。
- `GET /ai/native/video/kepu/tasks/{task_id}/assets`：项目资产记录。
- `POST /ai/native/video/kepu/tasks/{task_id}/exports`：导出 MP4 或剪映草稿。
- `GET /ai/native/video/kepu/config`、`PUT /ai/native/video/kepu/config`：API 配置。

### 6.2 v1 前端可本地管理的草稿字段

在后端正式支持项目草稿前，前端可用本地存储保存未提交任务：

- `draft_id`
- `name`
- `input_mode`
- `brief`
- `manuscript`
- `ratio`
- `visual_style`
- `text_style`
- `voice_type`
- `voice_name`
- `voice_speed`
- `updated_at`
- `created_task_id`

### 6.3 建议后端后续补齐

- 项目草稿保存接口：创建任务前也能持久化项目。
- 文稿版本接口：支持文稿自动保存、版本恢复。
- 任务恢复接口：返回失败任务已保存阶段和可继续操作。
- 统一资产搜索接口：跨任务检索图片、音频、字幕和导出文件。

## 7. 非功能需求

- 本地优先：生成素材继续保存到 `data/media/` 和 `output/`，媒体访问走 `/media/{file_path}`。
- 性能：项目资产页首次加载应在 2 秒内展示列表或骨架屏。
- 生成限速：生图并发默认保持 `IMAGE_CONCURRENCY=1`，请求间隔至少 3 秒。
- 错误恢复：刷新页面、任务失败、后端重启后，已入库的分镜和资产仍可访问。
- 可观测性：失败原因应包含 provider、阶段、可恢复建议。
- 可访问性：主要按钮、输入框、分段控制必须有可读标签和禁用态。

## 8. 验收标准

主流程：

- 用户打开首页后能直接进入文稿编辑页。
- 用户能在首页粘贴文稿、导入文档或用 AI 辅写生成脚本。
- 文稿为空但有 AI 辅写要求时，下一步按钮先生成脚本。
- 用户能保存文稿并进入视频生产页。
- 用户能确认生产参数并提交任务。
- 任务完成后自动进入预览编辑页。
- 用户能进入导出页生成 MP4 或剪映草稿。

恢复流程：

- 刷新文稿编辑页后，草稿内容仍存在。
- 任务生成中返回项目资产页，项目资产页显示生成中状态。
- 任务失败后，项目仍出现在资产页。
- 失败任务已生成的分镜、图片、音频能继续在预览编辑页展示。

编辑流程：

- 预览编辑页按 `segment_index` 顺序展示分镜。
- 用户能修改单段文案并保存。
- 用户能重生成单段图片。
- 用户能重生成单段配音。
- 用户能上传本地图片替换单段画面。
- 修改后可重新导出。

配置流程：

- 生产页能读取当前 API 配置状态。
- 任一必要 API 配置缺失时，生产页显示缺失项，阻止开始生产，并提供进入 API 配置页的明确入口。
- API 配置变更后，新提交任务使用新配置。
- 旧任务资产不因配置变更被破坏。

边界流程：

- 无 API Key 时，生产页阻止提交并提示配置入口。
- 生图 429 时，用户能看到限速/等待提示。
- TTS 失败时，已生成图片和分镜仍可查看。
- 导出失败时，预览编辑结果不丢失。
- 素材文件缺失时，分镜行显示缺失状态而不是空白崩溃。

## 9. 不做范围

v1 不包含：

- 云端多用户协作。
- 账号体系和权限管理。
- 在线支付和商业额度系统。
- 模板市场。
- 多人实时编辑。
- 复杂时间线剪辑器。

## 10. 实施建议

第一阶段先完成前端信息架构重排和文稿草稿本地保存，复用现有生成接口，保证主流程闭环。

第二阶段补齐后端项目草稿、文稿版本和任务恢复接口，把本地草稿能力迁移到数据库。

第三阶段优化资产搜索、跨项目复用和导出历史，让 InsightCut 从单任务工具升级为可长期使用的内容生产工作台。
