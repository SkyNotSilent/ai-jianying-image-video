## 🎯 实际导入测试

### 自动化测试 vs 实际导入

| 测试类型 | 覆盖范围 | 优点 | 局限性 |
|---------|---------|------|--------|
| 自动化测试 | 格式、结构、引用 | 快速、可重复 | 无法测试渲染效果 |
| 实际导入 | 完整功能 | 真实环境 | 需要手动操作 |

**建议流程：**
1. ✅ 先运行自动化测试（秒级）
2. ✅ 测试通过后再实际导入（分钟级）

### macOS 实际导入步骤

```bash
# 1. 运行测试
make test-latest

# 2. 如果测试通过，复制到剪映目录
cp -r output/项目名称 ~/Movies/JianyingPro\ Drafts/

# 3. 打开剪映专业版
# 4. 在草稿列表中找到项目
# 5. 打开并验证
```

### 验证清单

在剪映中打开项目后检查：

- [ ] 草稿能正常打开（无报错）
- [ ] 视频片段按顺序排列
- [ ] 音频正确对齐
- [ ] 字幕显示正常
- [ ] 播放流畅无卡顿
- [ ] 时长正确
- [ ] 素材完整加载

## 🐛 常见问题

### Q1: 测试通过但剪映打不开？

**A:** 自动化测试只能验证格式，某些兼容性问题需要实际导入才能发现。

**解决方法：**
1. 查看剪映的错误提示
2. 对比手动创建的草稿文件
3. 提供错误信息以便改进测试工具

### Q2: 时间轴有间隙警告？

**A:** 这通常不影响导入，但可能导致播放时有黑屏。

**解决方法：**
- 检查片段时长计算逻辑
- 确保 `target_timerange` 连续

### Q3: 素材文件不存在？

**A:** 生成流程可能有问题。

**解决方法：**
```bash
# 检查素材目录
ls -la output/项目名称/images/
ls -la output/项目名称/voiceovers/

# 检查生成日志
tail -f logs/app.log
```
